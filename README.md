# Mudawwar UI

A modern user interface for a waste management and recycling platform.

## Overview
Mudawwar is designed to help users track recycling activities and encourage sustainable behavior through a clean and user-friendly interface.

## Features
- User dashboard
- Waste tracking system
- Rewards and points system
- Clean and modern design

## Project Structure
- Screens for different app pages
- HTML code for each UI screen
